# Titanic Exploratory Data Analysis

## Project Overview
This project explores the Titanic passenger dataset using Python. It examines missing values, duplicate rows, passenger characteristics, and survival rates.

## Dataset
Source: Kaggle Titanic competition  
https://www.kaggle.com/competitions/titanic/data

Main analysis file: `train.csv`

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
- Dataset inspection and summary statistics
- Missing-value analysis
- Duplicate-row check
- Survival analysis by gender
- Survival analysis by passenger class
- Data visualization

## Key Findings
- Age has 177 missing values.
- Cabin has 687 missing values.
- Embarked has 2 missing values.
- The duplicate-row check returned 0.
- Female survival rate: 74.20%.
- Male survival rate: 18.89%.
- First-class survival rate: 62.96%.
- Second-class survival rate: 47.28%.
- Third-class survival rate: 24.24%.
